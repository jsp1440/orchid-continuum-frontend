# HOMEPAGE-RECOVERY-001 — Language Guidance

## Wonder is an outcome, not homepage copy

The homepage is intended to **inspire wonder through the experience**. The word `wonder` should not be used as a section title, navigation label, CTA, narrative-stage label, or self-description that tells visitors what emotion they are supposed to feel.

This guidance supersedes the `WONDER — living orchid hero` label in `HOMEPAGE-RECOVERY-001-DESIGN-CONVERGENCE.md` and the `Wonder → ...` shorthand in issue #163 / PR #164 descriptions.

For design and implementation purposes, refer to the opening stage neutrally as **Opening / Living Orchid Hero** (or simply **Hero**) until final public copy is reviewed.

The principle is:

> The page should create the conditions for wonder through extraordinary orchids, visual beauty, discovery, relationships, scale, place, and scientific insight. It should not announce or prescribe wonder.

Language review should therefore flag uses of `wonder` in public copy unless the word is genuinely necessary in a quoted or contextual passage. The preferred approach is to show, not tell.
